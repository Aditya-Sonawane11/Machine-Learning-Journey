## Project Overview
This project uses a Seattle Weather dataset to do exploratory data analysis on it.  
The analysis is done using:  
  1. **Pandas** : Data Manipulation
  2. **Numpy** : Mathematical Calculations
  3. **Matplotlib** : Data Visualization

## Objectives
To be able to use Python, Numpy, Pandas and Matplotlib on a real dataset and use it for analysis

## Dataset
The dataset contains approx. 1461 weather records from 1 January 2012 to 31 December 2015

| Column Name | Description |
|:-----------:|:-----------:|
|`date`|Date of weather records|
|`precipitation`|Amount of precipitation|
|`temp_max`|Maximum Temperature|
|`temp_min`|Minimum Temperature|
|`wind`|Wind Speed|
|`weather`|Type of Weather Condition|
